Entry for the [One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610)
bounty on make.fun: one original line, at most 200 characters, roasting a gadget
used every day, written to `/output/entry.txt` by `main.py`.

The roast:

> My dishwasher leaves exactly one glass dirty every load, like it's keeping a hostage for negotiations.

It was picked from six candidates scored against the judge brief's criteria
in order — a daily gadget named outright, a sting that lands on first read,
a fresh angle (no robot vacuum, no dying earbuds, no buzzing smartwatch,
none of the field's clusters), tight at 102 characters, and a specific
personal gripe with a concrete detail: exactly one glass, every single load.
